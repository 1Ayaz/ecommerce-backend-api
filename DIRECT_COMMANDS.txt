COPY AND PASTE THESE COMMANDS ONE BY ONE INTO YOUR TERMINAL:

STEP 1: Fix Node.js Conflicts
──────────────────────────────────────────────────────────────────────────────
sudo apt remove -y libnode-dev nodejs-doc npm


STEP 2: Configure Package Manager
──────────────────────────────────────────────────────────────────────────────
sudo dpkg --configure -a
sudo apt install -f -y


STEP 3: Update System
──────────────────────────────────────────────────────────────────────────────
sudo apt update
sudo apt install -y curl git


STEP 4: Install Node.js 20
──────────────────────────────────────────────────────────────────────────────
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -


STEP 5: Install Node.js Package
──────────────────────────────────────────────────────────────────────────────
sudo apt-get install -y nodejs


STEP 6: Verify Installation
──────────────────────────────────────────────────────────────────────────────
node --version
npm --version


STEP 7: Install PM2
──────────────────────────────────────────────────────────────────────────────
sudo npm install -g pm2


STEP 8: Install Nginx
──────────────────────────────────────────────────────────────────────────────
sudo apt install -y nginx


STEP 9: Create App Directory
──────────────────────────────────────────────────────────────────────────────
sudo mkdir -p /var/www/mubarak
sudo chown $USER:$USER /var/www/mubarak
cd /var/www/mubarak


STEP 10: Clone Repository
──────────────────────────────────────────────────────────────────────────────
git clone https://github.com/1Ayaz/mubarak-fresh-chicken.git .


STEP 11: Install Backend Dependencies
──────────────────────────────────────────────────────────────────────────────
cd backend
npm install


STEP 12: Install Frontend Dependencies
──────────────────────────────────────────────────────────────────────────────
cd ../client
npm install


STEP 13: Build Frontend (takes 2-3 minutes)
──────────────────────────────────────────────────────────────────────────────
npm run build


STEP 14: Setup Logs and PM2
──────────────────────────────────────────────────────────────────────────────
cd ..
mkdir -p logs
pm2 start ecosystem.config.js
pm2 save


STEP 15: Configure Nginx
──────────────────────────────────────────────────────────────────────────────
sudo cp nginx.conf /etc/nginx/sites-available/mubarak
sudo ln -sf /etc/nginx/sites-available/mubarak /etc/nginx/sites-enabled/mubarak
sudo rm -f /etc/nginx/sites-enabled/default


STEP 16: Test and Restart Nginx
──────────────────────────────────────────────────────────────────────────────
sudo nginx -t
sudo systemctl restart nginx


STEP 17: Configure Firewall
──────────────────────────────────────────────────────────────────────────────
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp


STEP 18: Check Status
──────────────────────────────────────────────────────────────────────────────
pm2 status


STEP 19: Find Your Public IP
──────────────────────────────────────────────────────────────────────────────
curl ifconfig.me

TROUBLESHOOTING:
══════════════════════════════════════════════════════════════════════════════

If npm install fails with ERESOLVE:
   npm install --legacy-peer-deps

If port 80 already in use:
   sudo systemctl stop apache2
   sudo systemctl disable apache2
   sudo systemctl restart nginx

If permission denied:
   Add sudo before the command
