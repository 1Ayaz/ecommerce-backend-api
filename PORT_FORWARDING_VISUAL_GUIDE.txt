TROUBLESHOOTING
══════════════════════════════════════════════════════════════════════════════

❌ Can't login to router (192.168.0.1 doesn't work):
   Try these addresses:
   • http://192.168.1.1
   • http://192.168.1.254
   • http://10.0.0.1
   
   Or find it:
   1. Open Command Prompt
   2. Type: ipconfig
   3. Look for "Default Gateway"

❌ Wrong password:
   Try these common defaults:
   • admin / admin
   • admin / password
   • admin / (leave blank)
   • Check router label (bottom of router)

❌ Can't find Port Forwarding menu:
   • Look in "Advanced" settings
   • Look for "NAT" or "Forwarding"
   • Check router manual
   • Google: "YOUR_ROUTER_BRAND port forwarding"

❌ Port forwarding not working:
   1. Check server is running:
      ssh ayaz1@192.168.0.6
      pm2 status
   
   2. Restart router:
      Unplug power, wait 30 seconds, plug back in
   
   3. Check from local network first:
      http://192.168.0.6
